# AGENTS.md — единые правила для AI-агентов biblio

Этот файл — **единственный канонический вход для любой нейросети**: Codex, Claude Code,
Gemini CLI и других агентов. Инструкции конкретного инструмента могут дополнять его, но
не должны дублировать или переопределять проектные правила.

## Что это за репозиторий

- **Склад** старых, обычно недоделанных утилит владельца (~2019–2021: VK-автоматизация,
  Instagram, WhatsApp, крипто-учёт, серверные шпаргалки). Ценность — **источник идей**:
  что-то в будущем доделаем/переделаем. Каталог — в [README.md](README.md).
- **Дом desktop-утилит экосистемы** ([D-048](../brain_matrica/docs/DECISIONS.md),
  2026-08-26): `tools/` — audio-to-text, video-downloader, net-monitor. Каркас
  «CLI-ядро + GUI + install.ps1 + Запустить.cmd» — в [tools/README.md](tools/README.md).
  Новый инструмент заводится здесь; слэш-команда-указатель — у Мозга.
- Репозиторий **публичный**. Ветка по умолчанию — **`master`** (не `main`).

## Статус в экосистеме

- biblio **не входит в реестр проектов** Мозга (D-048, постулат 10): без фаз,
  kill-policy и приоритетов. Это склад, а не управляемый проект.
- При этом **сессии здесь ведутся по канону экосистемы** (распоряжение владельца
  2026-08-26): session-команды, SESSION_HANDOFF, PR-flow — как у остальных репо.
- Почтового канала `mailboxes/biblio/` у Мозга **пока нет**. Письма Мозгу кладём в
  `mailbox/to-brain/*.md` этого репо (формат — [mailbox/README.md](mailbox/README.md));
  Мозг заберёт их, когда владелец решит открыть канал. Тишина = норма.
- `../brain_matrica` разрешено **только читать**. Никогда не изменяй, не коммить и не
  синхронизируй чужие репозитории (ни `fetch`, ни `pull`, ни `checkout` — мандат
  владельца 2026-08-04).

## Язык

Финальные сообщения, summary и рекомендации владельцу — **на русском**.
Internal reasoning, commit messages, идентификаторы — English.

## Начало и завершение работы

1. Синхронизируй **только этот** репозиторий (`git fetch`, безопасный fast-forward).
2. Прочитай `docs/SESSION_HANDOFF.md`, проверь `git status` и последние коммиты.
3. Если существует `../brain_matrica/mailboxes/biblio/from-brain/` — прочитай входящие
   (read-only); если каталога нет — канал ещё не открыт, это норма.
4. В конце значимой работы обнови `docs/SESSION_HANDOFF.md` и оставь репозиторий
   запушенным и чистым.

Исполняемые памятки — `.claude/commands/start.md`, `close_session.md`, `obriv.md`;
несмотря на имя каталога, их workflow применим к любому агенту.

## Git и совместная работа нескольких агентов

- `master` защищён логически: ветка → коммит → push → PR → squash merge. Прямой push
  в `master`, force-push и `reset --hard` запрещены.
- Один агент — одна задача, отдельная ветка; при одновременной работе — отдельный
  `git worktree`. Незнакомые изменения в дереве — чужие: не удалять, не форматировать,
  не включать в свой коммит, не stash'ить.
- Один PR — одна задача. Коммиты — Conventional Commits.
- После обрыва восстанавливай состояние из Git/PR (`/obriv`), не по памяти чата.

## Правила склада (legacy-код)

- Старый код (корень, `moduls/`, `history_postopus/`, `sumatra/`, `instructions/`) —
  **музей идей**: не рефакторить, не «чинить» и не удалять без явной просьбы владельца.
  Доделка утилиты = осознанная задача сессии, а не попутная уборка.
- Legacy-файлы могут содержать протухшие секреты и личные данные. **Не копируй** их
  содержимое в новые файлы, письма и документацию; новую находку такого рода — доложи
  владельцу (историю не переписываем: чистка трекинга ≠ отзыв, лечение — ротация).

## Публичный репозиторий — recon-поверхность

Ограничение через **свойство информации, а не канал** (D-038, #189): хостнеймы и IP,
SSH-алиасы, порты, пути на серверах, состав жильцов боксов, имя хостера — **не кладём
в отслеживаемые файлы вообще**: ни в код, ни в доки, ни в письма `to-brain`. Место
таких деталей — brain-сторона (приватна) или env вне репозитория. Секреты не должны
жить в репозитории даже под защитой `.gitignore`.

## Какие AI-файлы хранить в Git

Коммитить: `AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `.claude/commands/`,
`.claude/settings.json`, `docs/SESSION_HANDOFF.md`, `mailbox/`.
Не коммитить: `.claude/settings.local.json`, кэши `.codex/`/`.gemini/`, `.env*`,
ключи, токены, логи, тяжёлое в `tools/` (venv, модели, бинарники — gitignored).
