## 3. Проверь целостность недавно записанных файлов (грабля харнесса)

Обрыв может совпасть с **битой записью файла**: лишний `NUL`-байт (или UTF-16/BOM) →
git показывает файл как **`Bin`** в `git diff --stat`.

```bash
git add -A && git diff --cached --stat   # любой текстовый файл как "Bin" → подозрение
```

Если текстовый файл показан бинарным — вычистить NUL, пересохранить UTF-8:

```bash
node -e "const fs=require('fs');const f=process.argv[1];const b=fs.readFileSync(f);const n=[...b].filter(x=>x===0).length;console.log(f,'NUL',n);if(n)fs.writeFileSync(f,Buffer.from([...b].filter(x=>x!==0)))" '<путь>'
```

Отдельно про кодировки этого репо: `.ps1` — **UTF-8 с BOM** (иначе PowerShell 5.1
читает как ANSI и кириллица ломается), `.cmd` — ASCII без BOM, `.md` — UTF-8 без BOM.
