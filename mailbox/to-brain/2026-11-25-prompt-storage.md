# Коротко

**Промт #94 из раздела `MiniGen` выполнен** (план из библиотеки сверен с
кодом и сделан). В «МиниГене» появилось **«Хранилище промтов»**: место, где
лежат промты и планы по проектам, с **выбором места хранения** — в базе
«МиниГена» (локально, работает без сети) или **на внешнем ресурсе** (Карман со
своим хранилищем промтов).

И главное из заказа владельца: **программа сама отдаёт промты рабочим областям
проектов** — для заданий на самостоятельное программирование без живого
оператора.

Просим **выпустить `PROMPTS_TOKEN_MINIGEN` грантом в комнату `biblio`**: без
токена раздела программа не может архивировать промты — раздел отдаёт `503`
(это касается и ранее выполненных #96, #98, и дубля #122).

# 1. Что сделано (PR #152, слит в master)

- **Мост** — `bridge/minigen_prompts.py`: два провайдера хранилища за одной
  формой записи (`PromptRecord {id, project, title, body, kind, archived,
  createdAt, source, auto}`):
  - `LocalPromptStore` — в базе «МиниГена» (SQLite,
    `%LOCALAPPDATA%\minigen-gui\prompts.db`): работает всегда и без сети;
  - `KarmanPromptStore` — внешний ресурс: разделы читаются секретом канала
    (он приходит в программу сам из vault-комнаты), архивирование — токеном
    раздела из той же комнаты.
  - **Выбор места — настройка окна** (`promptStore`): данные каждого
    хранилища живут у своего хозяина, переключение место ничего не переносит.
- **Команды моста**: `prompts.list`, `prompts.save`, `prompts.archive`,
  `prompts.mark`, `prompts.dispatch`. **Инструменты нейросети**: `prompts.read`
  и `prompts.dispatch` (опасный — тратит очки аккаунта области, поэтому только
  с подтверждением владельца).
- **Окно** — вкладка **«Промты»**: место хранения (честно, включая состояние
  «недоступно» вместо тишины), выбор раздела, поиск по всему тексту, таблица
  промтов и планов, действия «В область» / «Авто» / «В архив» — с
  подтверждением, и форма добавления промта. В «Настройках» — где хранить и
  автораздача.
- **Автораздача без живого оператора** — поток моста раз в минуту.

# 2. Правила, которые проверяет мост (окно их не обойдёт)

- **раздел промта = проект области**: промт раздела `MatricaRMZ` идёт в область
  `matricarmz`; в чужую область не уйдёт — отказ с объяснением;
- **без живого оператора раздаётся только то, что владелец сам пометил**
  («авто»), и только в область своего проекта; обычный промт без спроса не
  раздаётся никогда;
- **архив = сделано**: архивирует тот, кто выполнил;
- **секреты — не в репозитории и не в журнале**: адрес и токены берутся из
  vault-комнаты, наружу уходит только источник.

# 3. Развилки, которые план отдал владельцу — как решено

1. **Автораздача** — так, как предлагал план: только помеченное владельцем и
   только в область своего проекта. Оба пути на месте: «по команде оператора»
   (кнопка «В область», инструмент `prompts.dispatch`) и «по триггеру» (поток
   моста); выбор — переключатель в «Настройках», по умолчанию выключено.
2. **План из хранилища** — уходит вместе с промтом, если план лежит рядом в
   том же разделе; окно показывает текст задания до подтверждения.
