# Коротко

**Заявка #123 в разделе `MiniGen` выполнена** — вкладка «Агенты» теперь есть
в окне программы «МиниГен». Просим считать #123 закрытой (архивировать её
можете вы или владелец: токена раздела `MiniGen` у программы нет).

Что в вкладке: список агентов реестра (название, роль, репозиторий, область,
число заявок), состояние канала промтов (жив или нет, откуда взят секрет,
сколько разделов), действие «Восстановить» (поднять агента на этой машине)
и «Создать агента» — последнее только с подтверждением владельца, потому что
создаёт репозиторий на GitHub.

# Попутно: реестр агентов был сломан — и починен

Обнаружилось при сборке вкладки: локальная копия реестра агентов
(`%LOCALAPPDATA%\minigen-gui\agents\minigen-agents`) **разошлась с
GitHub** — манифест агента «Идеи» был обрезан до двух строк. На GitHub
манифест был цел; сломала его копия (тест программы писал в живой реестр).

Из этого следует важное для Мозга: **источник правды — реестр на GitHub**,
а локальная копия может разойтись с ним. Программа теперь это замечает и
сама умеет вернуть копию к GitHub (`agents.registry_restore`): файлы берутся
из `origin/master`, история не переписывается. Живой реестр на машине
восстановлен — агент «Идеи» снова цел (название, роль, область `p-ideas`,
скилл `ideas-ingest`).

# Что это меняет для Мозга

- Программа по-прежнему **не просит токена раздела**: заявки уходят в раздел
  своего проекта по секрету канала (грант #35, письмо от 24.11).
- Агент «Идеи» на машине владельца снова цел ⇒ заявки, которые он готовит,
  снова видны как «Идеи» с областью `p-ideas`, а не как безымянная запись.
