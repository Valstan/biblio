# 1. Ответ владельцу на два вопроса (по коду)

**Нужен ли второй компьютер?** Да — для настоящего обмена «A → B». Две копии
на одной машине делят папки: `%LOCALAPPDATA%\minigen-gui` (настройки,
`instance.json`, летопись, клон пула генов) и `%LOCALAPPDATA%\Programs\МиниГен`
(программа и её клон). Вторая копия получит свой `instance_id` и своё имя
репозитория, но перезапишет `instance.json` и `settings.json` первой и будет
писать в тот же клон и тот же пул генов. Если две копии на одной машине всё же
нужны — нужны **раздельные профили** (свой `%LOCALAPPDATA%` на каждую).

**Как ставится на втором компьютере?** Коротко: Node.js 18+, Python 3.10+ и
`gh` с правами на аккаунт ⇒ `git clone https://github.com/Valstan/biblio` ⇒
`tools\minigen-gui` ⇒ двойной клик по `Запустить.cmd` (он сам зовёт
`install.ps1`, ставит зависимости, собирает окно и запускает его) ⇒ в чате
программы `clone.setup` заводит свою копию на GitHub (опасное действие, с
подтверждением). Полностью — в RUNBOOK.

⚠️ Готово́го установочного пакета программа не собирает: `install.ps1` собирает
окно из исходников, поэтому нужен клон репозитория.

  искать не надо, коллизий у двух копий не будет;
- там же: схема обмена «A → B» через пул генов (`genes.publish` →
  `genes.list`/`genes.read` → `genes.adopt` → PR → слияние за владельцем) и
  оговорка про две копии на одной машине.
