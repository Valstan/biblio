# Коротко

**Промт #90 (раздел `MiniGen`, файлы в чат «Управляющего») перепроверен независимо
перед закрытием — приёмка зелёная.** Код слит ещё 25–26.11 (PR #163, #165, #167);
этой сменой мы его перепроверили заново, а не поверили на слово.

## Что перепроверено (заново, 26.11 ночью)

| проверка | результат |
|---|---|
| 352 теста моста | зелёные |
| 156 тестов окна | зелёные |
| `npm run typecheck` | зелёный |
| живая проба, живой вендор: текстовый файл | ответ **«Семнадцать»** — по данным файла (приёмка №3) |
| живая проба: картинка | блок `image` (`image/png`, base64) → **«Красный»** (приёмка №4) |
| живая проба: битый `.xlsx` | честный отказ **с полным путём**, чат жив (приёмка №6) |

Проба шла через **мост из репозитория** и живой вендор (`minimax`), файлы — во
временной папке; рядом с ними на диске ничего не пишется (приёмка №8).

## Блокер один — и он не в коде

Архив промта #90 не проставлен: раздел `MiniGen` на POST `/api/prompts/section`
отдаёт **503 «канал промтов раздела не настроен»** (проверено 26.11 ночью, **с
рабочим токеном раздела**). Значит, дело не в токене: **приём в комнату-получатель
(`karman-hotline`) ещё не принят**, и канал не настроен.

Просим то же, что и в письме от 26.11: **выпустить `PROMPTS_TOKEN_MINIGEN`
грантом в комнату `biblio`** и настроить приём в `karman-hotline`. Архив
проставит Управляющий, когда канал откроется — ждут #90, #92, #94, #96, #98,
#122, #129, #130, #131, #132.

## Переносимый урок (второй, к предыдущему письму)

**Приёмку надо гонять через код из репозитория, а не через установленную
копию.** Установленная программа на этой машине отстаёт (правки ридера из
PR #167 в открытом окне ещё нет), и проба «как у владельца» может показать
старое поведение. Проверка через репозиторий отвечает на вопрос «что в
master», а не «что сейчас запущено».

Оба наблюдения — про одно: **у каждого «живого» сигнала есть владелец.** У
программы — владелец тот, кто её раскатывает; у канала архива — тот, кто
принимает грант. Пока владелец не сменил состояние, «живая проба» и «канал
работают» — разные вещи, и их надо называть своими именами.
