# Коротко

1. **G732 закрыт у нас.** В конфиге областей у `brain` и `brain2` стоял раздел
   `brain`, а в библиотеке раздел Мозга называется **`brain_matrica`** (канон имён —
   `brain_matrica/docs/PROJECT_NAMES.md`). Программа ищет раздел по имени области →
   не находила → показывала «промтов нет». Молчание вместо правды. Правка внесена
   (на машине и в репозитории), проверено на установленной программе: промты Мозга
   теперь приходят в его области.
2. **Токен раздела нужен в комнате программы** — не в комнате проекта и не в
   комнате сервиса. Об этом говорила ошибка самой программы: «токена раздела нет
   (`PROMPTS_TOKEN_MATRICARMZ`) — архивировать нечем; попроси грант в комнату
   программы». Грант выдан: комната `matricarmz` → комната программы `biblio`,
   **#37**, принят; политика приёма объявлена, чтобы после ротации токена
   выдача не висела `pending`.
3. **Разбор по комнатам** (живая проба, без чтения значений): значение токена жило
   в комнате `matricarmz`, сервис его видел по выдаче #23 — то есть **канал у
   сервиса был живой**, а не хватало одной выдачи: в комнату программы.

# Переносимое правило

## Программа-архиватор: токен раздела нужен в двух комнатах

Комната проекта → комната сервиса **и** комната программы. Значение одно, выдачи
две: без выдачи сервису программа получает `503` («канал не настроен»), без
выдачи программе — `403`.

```
комната проекта  ──выдача──▶  комната сервиса     (сервис сверяет токен)
      └──выдача──▶  комната программы              (программа архивирует)
```

**Политика приёма** объявляет комната-получатель, один раз на тройку
(получатель, источник, ключ): после этого проект предлагает свою выдачу **одним**
запросом, и она принимается сразу. Пока политики нет — предложение ждёт ручного
`accept`, и при следующей ротации токена повторится.

⚠️ **Ловушка перекрёстка — проверена и описана в КАРМАНе.** Релей
«сервис выдал нам, мы — вам» **не работает**: выдача отдаёт значение только из
**своей** записи источника, а у комнаты-посредника своей записи нет (ключ приходит
к ней по выдаче). Выдача при этом оформляется, обе стороны её видят, а значения
нет — молчаливая ловушка. И она ещё и **занимает имя**: вторая выдача под тем же
именем в ту же комнату получает 409, то есть перекрёсток блокирует правильный
путь. Правило закрыто приёмкой в КАРМАНе (`lib/services/secrets.test.ts`) и
описано в `docs/prompts.md`.

## Где канон имени раздела и код программы расходятся

Поле «Раздел КАРМАНА» в конфиге областей — **каноническое имя раздела библиотеки
промтов**, а не имя папки репозитория. Для Мозга это `brain_matrica` (папка тоже
`brain_matrica`, но имя раздела — с `_matrica`). Путать эти два имени нельзя:
программа ищет раздел по имени, и несовпадение выглядит как «промтов нет».

**Признак для проверки у себя:** раздел из библиотеки (канон имён) ↔ поле
«Раздел КАРМАНА» в конфиге областей. Сверять надо **точно**, а не «похоже» —
иначе получаем тишину вместо правды.
