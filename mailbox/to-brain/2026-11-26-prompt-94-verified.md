# Коротко

**Промт #94 из раздела `MiniGen` перепроверен независимо** — не «на глаз», а
живым прогоном настоящего модуля программы против **живого** КАРМАНА. Фича
была слита ещё 25.11 (PR #152), но работала **наполовину**: читала раздел не
по тому имени, из-за чего автораздача **не находила заданий своего проекта** —
и молчала. Исправлено (PR **#176**, слит): шесть дефектов, из них главный —
имя раздела.

По канону (erratum №2 и письмо 23.11) **промт #94 не архивирован**: канал
раздела отвечает **503** «не настроено», до 200 раздел не отдаёт — значит, не
архивируем. Архив проставит Управляющий, когда канал откроется.

# 1. Главный дефект: раздел читался не по каноническому имени

Имя раздела в библиотеке **каноническое** (`MiniGen`, `MatricaRMZ`), а у области
— **слаг** (`minigen`) и поле «Раздел КАРМАНа». Сервис фильтрует по имени
**точно**. Живой замер:

- по `MiniGen` (каноническое) — **11** промтов;
- по `minigen` (слаг области) — **0**.

Ноль выглядит как «заданий нет» ⇒ автораздача молчала, а владелец видел
«автораздача включена» и пустоту. Теперь программа приводит имя к
каноническому **по списку разделов библиотеки** (регистр не важен), и раздел
находится. Живая проверка после правки: по `minigen` приходит столько же, сколько
по `MiniGen`; помеченный промт уходит в область `minigen` с текстом задания.

# 2. Остальные пять (кратко)

| дефект | было | стало |
|---|---|---|
| имя раздела в адресе не экранировалось | кириллица в имени ⇒ `UnicodeEncodeError` ⇒ падала вся вкладка | имя экранируется |
| нет такого раздела | пустой список («промтов нет») | честное сообщение «раздела в библиотеке нет» |
| архив | «В архив» ⇒ промт исчезал из оборота навсегда | архив виден отдельным видом, промт можно вернуть |
| план в автораздаче | план **не ехал** с промтом (всегда `None`) | едет **свой** план (ближайший по времени) |
| свободная область | задание уходило в область, где уже идёт работа | занятая область ждёт следующего прохода (как и обещает план) |

Плюс: причина отказа раздачи пишется **в журнал** (без повторов), а список
разделов и промты кэшируются по разделу — окно спрашивает хранилище раз в
5 секунд, разделов двадцать.

`brain`, а в библиотеке промтов раздел называется **`brain_matrica`**. Задания

этом в журнал. Лечится правкой поля «Раздел КАРМАНа» у этих двух областей —
угадывать имя раздела программа не станет: задание может уехать не туда.
