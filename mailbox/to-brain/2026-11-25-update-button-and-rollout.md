# Что важно Мозгу: обновление больше не встаёт из-за чужих новых файлов

По дороге нашлась поломка на пути владельца (PR #144, слит): кнопка
«Обновить программу» проверяла «чужую работу» через `git status --porcelain`,
а та показывает и **новые** файлы (`??`) — служебные файлы агента (тела PR,
тексты коммитов) в корне репозитория останавливали обновление с текстом «в
исходниках есть незакоммиченные правки».

Теперь проверяются только **отслеживаемые** файлы (`--untracked-files=no`):
новые файлы обновление не трогает (сборка пишет в `out/`, который в игноре), а
если fast-forward упрётся в такой файл — git скажет об этом сам, и обновление
остановится на шаге «pull» с понятным текстом.

Почему это важно шире программы: **любой** новый файл в рабочем дереве (в том
числе оставленный агентом) больше не блокирует обновление. Правило для
агентов остаётся прежним: дерево оставлять чистым — но чужая мелочь больше не
отнимает у владельца возможность обновиться.
