# clock — часы в одну строку в правом нижнем углу

Локальная утилита для Windows: **дата и время одной строкой, крупным шрифтом**,
в правом нижнем углу экрана, над панелью задач. Системные часы Windows 11 при
этом скрываются.

Движок: PowerShell + WinForms. Ноль зависимостей, работает оффлайн.

## Зачем

Windows 11 не умеет того, что нужно владельцу:

- размер шрифта часов в трее **не настраивается** вообще (Microsoft: способа
  нет, старые реестр-хаки не работают — код панели переписан);
- дата в трее всегда **второй строкой**, одна строка штатно недостижима.

Поэтому часы рисует эта утилита: формат задаётся строкой, шрифт — свой.

## Как выглядит

```
Чт, 26 ноя 2026, 10:54
```

## Установка (1 раз на машину)

`Установить.cmd` в этой папке — или вручную:

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```

Установщик:

1. копирует `clock.ps1` в `%LOCALAPPDATA%\Programs\clock\`;
2. создаёт ярлык в папке автозагрузки — часы появятся при каждом входе;
3. **скрывает системные часы** (`ShowSystrayDateTimeValueName = 0`);
4. запускает утилиту и печатает пути.

Повторный запуск безопасен — установщик идемпотентен.

## Запуск без установки

`Запустить.cmd` — просто запускает часы из этой папки (без автозагрузки и без
скрытия системных часов).

## Правка вида

Всё настраивается в блоке `CONFIG` в начале `clock.ps1`:

| Параметр | Что делает | По умолчанию |
|---|---|---|
| `$FontSize` | размер шрифта, пунктов | `13` (системные часы — около 9) |
| `$FontBold` | жирный | нет |
| `$FontFamily` | шрифт | `Segoe UI` |
| `$Format` | формат даты и времени | `ddd, dd MMM yyyy, HH:mm` |
| `$MarginRight` / `$MarginBottom` | отступы от края экрана и от панели | `10` / `6` |
| `$ShowSystemClock` | скрывать ли системные часы | `$false` |

Формат — обычная .NET-маска, язык берётся из локали системы. Полезные варианты:

| Маска | Результат |
|---|---|
| `ddd, dd MMM yyyy, HH:mm` | `Чт, 26 ноя 2026, 10:54` |
| `dd MMMM yyyy, HH:mm` | `26 ноября 2026, 10:54` |
| `dd.MM.yyyy HH:mm` | `26.11.2026 10:54` |
| `HH:mm` | только время |

Правка файла требует перезапуска утилиты (правый клик по часам → Exit, потом
`Запустить.cmd`).

## Правка без правки файла

Правый клик по часам:

- **Bigger** / **Smaller** — размер шрифта на лету;
- **Show system clock** / **Hide system clock** — вернуть или скрыть системные
  часы;
- **Exit** — выход.

## Грабли

1. **Скруглённые углы ломают окно, если применить регион до показа формы.**
   Регион задаётся обработчиком `Shown` — иначе окно остаётся с пустым
   регионом и не рисуется ничего (проверено 26.11.2026).
2. **Часы нельзя нарисовать внутри полосы панели задач**: на Windows 11 панель
   рисуется поверх окон topmost. Чипа над панелью — единственный рабочий вариант.
3. **`New-Object System.Drawing.Font(...)` с тремя позиционными аргументами**
   падает: «Multiple ambiguous overloads found» (bool против FontStyle). Тип
   надо назвать явно: `New-Object System.Drawing.Font -ArgumentList @($family,
   [float]$size, $style)`.
4. **Функцию в PowerShell надо объявить до первого вызова** — файл выполняется
   сверху вниз, вызов функции ниже её объявления даёт «The term … is not
   recognized».
5. **Цвет плашки берётся пикселем с панели задач** (акрил, оттенок зависит от
   обоев). Если пиксель не читается — берётся цвет темы.
6. **Системные часы в Win11 скрываются ключом**
   `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced\ShowSystrayDateTimeValueName = 0`,
   иначе две даты рядом. Ключ меняется без перезапуска проводника, но панель
   мигает.
7. **Второй экземпляр не запустится** — поднят мьютекс `Local\clock-kompik`.
   Это защита от двойного запуска (автозагрузка + ручной старт).
8. **Сообщения и комментарии в `.ps1` — ASCII**: PowerShell 5.1 читает файл без
   BOM как системную ANSI-кодировку и портит кириллицу. Русская документация —
   здесь, в README.

## Откат

```powershell
# 1. убрать из автозагрузки
Remove-Item "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup\KompikClock.lnk"
# 2. снять утилиту
Remove-Item "$env:LOCALAPPDATA\Programs\clock" -Recurse
# 3. вернуть системные часы
Set-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced' `
  -Name 'ShowSystrayDateTimeValueName' -Value 1
```

## Отладка

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File clock.ps1 -DebugLog
```
Пишет `clock-debug.log` рядом со скриптом: позиция и размер окна, текст, цвет.
