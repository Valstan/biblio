# Настройка Касперского под «Матрица РМЗ» — инструкция

Этот файл сгенерирован программой `kaspersky-matrica` под ТЕКУЩИЙ компьютер: все пути
ниже уже подставлены реальные. Копируй строки как есть.

## Зачем это

Касперский по умолчанию сканирует и «сторожит» любую программу. Для «Матрицы РМЗ» это
даёт три беды: (1) тормозит запуск и работу (постоянное сканирование файлов приложения),
(2) сторож `matricarmz-watchdog.exe` — это программа на Go, а Go-файлы антивирусы часто
принимают за вирус по эвристике и удаляют/блокируют, (3) может резать соединение с
сервером. Лечится тремя добавлениями в Касперский: доверенные программы + исключения-папки
+ разрешение сети. Ниже — что именно и куда.

## Что программа нашла на ЭТОМ компьютере

- Касперский: **{{KAV_NAME}}**, версия **{{KAV_VERSION}}**
- avp.com: `{{AVP}}`
- Матрица (exe): `{{APP_EXE}}`
- Папка Матрицы: `{{APP_DIR}}`
- Сторож (watchdog): `{{WD_EXE}}`
- Папка сторожа: `{{WD_DIR}}`
- Данные Матрицы: `{{DATA_DIR}}`
- Сервер (куда Матрица шлёт данные): `{{PROD_HOST}}` (IP: {{PROD_IP}}), порт 443

Если какая-то строка пустая — этого компонента на этом компьютере нет (например, сторож
ставится вместе с приложением; если Матрица ещё не установлена, часть путей будет пустой —
запусти инструкцию снова после установки).

## ПУТЬ 1 — настроить ЭТОТ компьютер руками (5 минут, один раз)

Касперский **нельзя** настроить из командной строки по одному исключению и нельзя
«подсунуть файл в папку» (мешает Самозащита). Поэтому три добавления делаются в окне
Касперского. Открой: **значок Касперского в трее → Настройки (шестерёнка внизу) →
«Настройки безопасности» → «Исключения и действия при обнаружении угроз»**
(в некоторых сборках раздел называется «Угрозы и исключения»).

### A. Доверенные программы

Там же → **«Указать доверенные программы»** (или «Настроить доверенные программы») →
**Добавить** → указать путь к файлу. Добавь эти файлы:

```
{{TRUSTED_LIST}}
```

Для каждого поставь галочки:
- ☑ Не проверять открываемые файлы
- ☑ Не контролировать активность программы
- ☑ Не наследовать ограничения родительского процесса
- ☑ Не контролировать активность дочерних программ
- ☑ Разрешить взаимодействие с интерфейсом программы
- ☑ Не проверять сетевой трафик

Последняя галочка («не проверять сетевой трафик») закрывает и вопрос с сервером —
отдельное правило файрвола тогда не нужно.

### B. Исключения (папки)

Там же → **«Управление исключениями»** → **Добавить** → в поле «Файл или папка» вставь
по одной:

```
{{EXCLUDE_LIST}}
```

(Список собран под этот компьютер: папка приложения, папка сторожа, папка данных, папка
рабочих данных приложения — там лежат база и логи, это самая пишущая папка — и папка
обновлений, куда качается установщик.)

Компоненты защиты для исключения можно оставить «все». Это снимает файлы приложения со
сканирования полностью (доверенная программа не проверяет, что программа ОТКРЫВАЕТ, а
исключение-папка не проверяет сами файлы приложения — нужны оба).

### C. Сеть (если не поставил галочку «не проверять сетевой трафик» в пункте A)

Настройки → «Настройки безопасности» → **«Сетевой экран» → «Настроить пакетные правила»**
→ Добавить разрешающее правило: удалённый адрес `{{PROD_IP}}`, удалённый порт `443`,
протокол TCP, действие «Разрешать».

### Проверка

После этого запусти Матрицу. Если работает без блокировок — готово. Можно снова включить
защиту Касперского целиком: внесённые исключения останутся в силе.
Команда самопроверки: `kaspersky-matrica.ps1 -Verify`.

## ПУТЬ 2 — перенести настройку на ДРУГИЕ компьютеры (golden config)

Это то, что ты просил: один раз настроил — на остальных применил скриптом. Работает через
штатный экспорт/импорт настроек Касперского (`avp.com`), НО с двумя жёсткими условиями:

1. **Версия Касперского на всех компах должна совпадать** ({{KAV_VERSION}}). Импорт в более
   старую версию Касперский запрещает, в более новую — часть настроек сбросит в умолчания.
2. **Импорт переносит ВСЕ настройки Касперского целиком** (не только исключения Матрицы):
   уровни защиты, файрвол, интерфейс. Это клон всей конфигурации, а не «добавить одну
   программу». Поэтому эталон настраивай на чистом, правильно настроенном Касперском.

### Шаг 1 — на ЭТОМ (эталонном) компе, ПОСЛЕ пунктов A/B/C

Важно: чтобы один файл подошёл всем пользователям (у них другое имя пользователя в пути),
в пункте B добавляй исключения **масками** вместо конкретных путей — тогда они не привязаны
к имени пользователя:

```
{{MASK_LIST}}
```

(Доверенные программы из пункта A привязаны к конкретному пути и на чужом пользователе не
совпадут — но исключения-маски выше уже снимают файлы со сканирования, а сеть закрывает
правило файрвола на IP {{PROD_IP}}, оно тоже от имени пользователя не зависит. На каждом
компе доверенные программы при желании до-бавляются повторно, но это не обязательно.)

Затем сохрани эталон (запусти от администратора):

```
kaspersky-matrica.ps1 -Export "C:\Матрица-эталон-касперский.cfg"
```

(программа выполнит `avp.com EXPORT`). Файл `.cfg` — это весь снимок настроек.

### Шаг 2 — на каждом ДРУГОМ компе

Скопируй туда файл `.cfg` и запусти (от администратора):

```
kaspersky-matrica.ps1 -Import "C:\Матрица-эталон-касперский.cfg"
```

Программа выполнит `avp.com IMPORT` и применит весь снимок. Если в Касперском включён
пароль на управление настройками — добавь `-SettingsPassword "твой_пароль"`.

⚠️ Импорт ЗАМЕНЯЕТ всю конфигурацию Касперского на этом компе. Применяй только свой
эталонный файл, который сам же и сделал.

## Почему нельзя «полностью автоматически» и почему НЕ выйдет настроить, пока Касперский «спит»

- У потребительского Касперского **нет команды «добавить одно исключение»** — ни в
  командной строке, ни через реестр, ни файлом. Создаются только в окне (пункт A/B).
- **Самозащита Касперского** — отдельный механизм, он НЕ выключается вместе с защитой в
  реальном времени. Даже когда ты «выключил защиту», Самозащита продолжает блокировать
  любую попытку изменить настройки/файлы/реестр Касперского извне. Поэтому задумка
  «программа сама поменяет настройки, пока Касперский спит» не сработает — это защищено
  на уровне, который сном не выключается.
- Единственный поддерживаемый способ «без кликов на каждом компе» — клон всей конфигурации
  через EXPORT/IMPORT (ПУТЬ 2). Он есть, он рабочий, но переносит настройки целиком и
  требует одинаковой версии.

Вывод: настройка одного компа — руками в окне (5 минут, ПУТЬ 1); тираж на парк — импортом
эталона (ПУТЬ 2). Всё, что можно было автоматизировать, программа автоматизирует
(определение путей, готовые строки, экспорт/импорт); клики в окне за тобой — их Касперский
никому не отдаёт.
