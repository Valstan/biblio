# Аудио → текст (локально, GigaAM v2)

Десктоп-инструмент: накидал несколько голосовых/записей (ogg/mp3/wav/m4a/…) →
они **по очереди распознаются в фоне** → у каждого свой блок текста → пометил
галочками нужные и скопировал (по отдельности или объединив).

**Всё считается на твоём компьютере.** Ничего не уходит в облако (после разовой
установки пакетов и скачивания моделей). Распознавание —
[GigaAM](https://github.com/salute-developers/GigaAM) от SberDevices (лучшее
бесплатное по русскому), пунктуация и заглавные — [Silero](https://github.com/snakers4/silero-models)
`silero_te`.

Первый из класса инструментов «локальный скрипт + GUI» — см.
[`../README.md`](../README.md).

## Установка (1 раз на машину)

Нужен Python 3.10–3.12 ([python.org](https://www.python.org/downloads/), при
установке отметить «Add Python to PATH»).

```powershell
cd tools\audio-to-text
powershell -ExecutionPolicy Bypass -File install.ps1
```

Установщик идемпотентен — повторный запуск чинит/доустанавливает, не ломая
существующее. Тянет CPU-сборку PyTorch + GigaAM + ffmpeg (через `imageio-ffmpeg`,
без установки ffmpeg в систему). **Первое распознавание** дополнительно скачает
модель GigaAM (~1–2 ГБ) — это разово, дальше из кэша.

## Запуск

- Двойной клик по **`Запустить.cmd`**, либо
- `powershell -ExecutionPolicy Bypass -File run.ps1`

В окне:
1. **«➕ Добавить файлы…»** (или перетащи несколько файлов в окно) — каждый
   становится блоком и встаёт в очередь.
2. Файлы обрабатываются **в фоне по очереди**; статус блока: `в очереди` →
   `Фрагмент i/n…` → `✓ готово · N слов`. Окно можно не закрывать.
3. Галочкой слева помечаешь нужные блоки → **«📋 Копировать выбранные»** (объединит
   через пустую строку) или **«💾 Сохранить выбранные…»**. У каждого блока есть и
   своя кнопка **«📋 копировать»** — забрать только его.
4. Тумблер **«Пунктуация и абзацы»** вверху — вкл/выкл расстановку точек/запятых/
   заглавных и разбивку на абзацы (по паузам).

## Нарезка для бота SaluteSpeech (✂)

Иногда для трудной записи хочется качество бота
[@smartspeech_sber_bot](https://t.me/smartspeech_sber_bot), но он ограничен:
**≤5 минут, ≤20 МБ, моно** (MP3/WAV/FLAC/OggOpus). Кнопка **«✂ Нарезать для бота
SaluteSpeech…»** режет длинное аудио на **моно-mp3 фрагменты ≤4:40** (по паузам, не
рвёт на полуслове) в папку `<имя>_parts/` рядом с исходником → отправляешь их боту
по очереди. Распознавание тут не запускается — это только подготовка файлов.

CLI: `transcribe.py "запись.mp3" --split [--max-sec 280] [--out-dir DIR]`.

## Командная строка (без GUI / для скриптов и Claude)

```powershell
.venv\Scripts\python.exe transcribe.py "голосовое.ogg"
.venv\Scripts\python.exe transcribe.py "лекция.mp3" --model v2_ctc --out лекция.txt
.venv\Scripts\python.exe transcribe.py "сырой.ogg" --no-punct   # без пунктуации
.venv\Scripts\python.exe transcribe.py "час.mp3" --split         # нарезать для бота
```

Распознанный текст идёт в stdout; сообщения о ходе — в stderr.

## Модели

| Модель | Чем хороша |
|---|---|
| `v2_rnnt` (по умолч.) | Самая точная ASR в пакете |
| `v2_ctc` | Быстрее, чуть менее точная |
| `v1_rnnt` / `v1_ctc` | Старое поколение (на крайний случай) |

Сменить дефолт: переменная окружения `A2T_MODEL` или флаг `--model`.
### Пунктуация

Сам GigaAM в pip-пакете `gigaam 0.1.0` даёт «сырой» текст без пунктуации (моделей
v3/e2e с пунктуацией в пакете пока нет). Пунктуацию и заглавные ставит **отдельный
шаг** — Silero `silero_te` (маленькая, CPU, русская; качается разово при первом
включении). Тумблер «Пунктуация и абзацы» в GUI / флаг `--no-punct` в CLI.

## Как это устроено

- **Декод**: ffmpeg (из `imageio-ffmpeg`) приводит вход к 16 кГц моно WAV.
- **Длинные файлы**: GigaAM `transcribe()` берёт фрагменты ≤25с, поэтому длинная
  запись режется здесь по точкам тишины (ffmpeg `silencedetect`), фрагменты
  распознаются по очереди. Сделано **без** `pyannote`/`HF_TOKEN` — полностью оффлайн.
- **Пунктуация/абзацы**: каждый фрагмент-между-паузами прогоняется через Silero и
  становится абзацем (склейка через пустую строку).
- **Пакет**: модель грузится один раз и переиспользуется; файлы обрабатываются
  фоновым потоком по очереди — окно не подвисает, можно докидывать ещё.

## Если что-то не так

- **«Python 3 не найден»** — установи Python 3.11 с python.org, перезапусти терминал.
- **Установка падает на `tkinterdnd2`** — закомментируй эту строку в
  `requirements.txt`, перезапусти `install.ps1`. GUI работает и без drag-and-drop.
- **Долгое первое распознавание** — идёт скачивание модели (~1–2 ГБ). Дальше быстро.
- **Мало RAM** — torch + модель хотят ≥4 ГБ свободной памяти. На обычном десктопе ок;
  на 1–2 ГБ VPS — не запускать (упрётся в OOM).
