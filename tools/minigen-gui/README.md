# МиниГен — одна программа вместо панели и скриптов

**Что это.** Окно Windows, в котором видно и обслуживается «МиниГен» —
рабочие области MiniMax Code: их состояние, вход, очки, сессии, сеть,
статистика и журнал. До 23.11.2026 это было набор скриптов + веб-панель в
браузере (`127.0.0.1:8099`) и страница управления (`:8098`). Теперь это одно
окно, а логика сторожей осталась прежней — программа **показывает и
управляет**, а не переписывает то, что уже работает.

## Где программа живёт

| Что | Где |
|---|---|
| **Установленная программа** | `%LOCALAPPDATA%\Programs\МиниГен` — запуск: ярлык «МиниГен» на рабочем столе |
| Исходники | этот репозиторий (`tools/minigen-gui`) — программа знает путь (настройка `codeRepo`) и правит их через PR |
| Демоны «МиниГена» | `C:\Users\valstan\bin` — их ставит раскатка |

⚠️ Программа стоит **вне репозитория** намеренно: если бы она жила в
рабочем дереве, её версия зависела бы от того, какая ветка там checkout —
любой `git checkout` молча менял бы программу, запущенную у владельца.

**Обновление** (после `git pull` или мержа PR):

```powershell
python tools\minimax-project-areas\minigen_rollout.py
```

Раскатка обновит и демонов, и саму программу, и ярлыки.

**Установка на новый компьютер** — [INSTALL](docs/INSTALL.md): что нужно на
машине, откуда взять репозиторий и как запустить установщик. Вторая копия
программы = **отдельная машина** (порт API и каталоги фиксированы).


## Вкладки

| Вкладка | Что показывает | Что умеет |
|---|---|---|
| **Области** | все 19 областей: запущена ли, вход, очки, режим (Автомат/Вручную), вердикты сессий | старт, стоп, перезапуск, новый вход (токен), открыть папку, **создать область** |
| **Статистика** | события по причинам (отказ по очкам, обрыв сети, компактизация, потеря входа), по областям и видам | период 1/3/7/30 дней, экспорт CSV |
| **Сеть** | пути (прокси), вендор MiniMax, устойчивость связи, живые демоны | «Проверить все» |
| **Чат** | встроенная нейросеть MiniMax | отвечает по состоянию программы и **выполняет** команды через инструменты; опасные действия — с подтверждением |
| **Журнал** | общий журнал сторожей | фильтр по тексту и по тегу, режим «вживую» |
| **Черенки** | как поставить копию «МиниГена» другому человеку и как передать наработки (гены): инструкция, список «что отправить», пул наработок | скопировать инструкцию в буфер, открыть файл, опубликовать ген, выгрузить/внести папку наработок |
| **Настройки** | интервалы, область с конфигом провайдера, модель, подтверждения, пути | сохранить |

## Как запустить

### Установленная программа (обычный случай)

Ярлык **«МиниГен»** на рабочем столе → `%LOCALAPPDATA%\Programs\МиниГен`.
Ничего не нужно: программа сама поднимает мост, а демоны ведутся фоновым
режимом (автозапуск Windows, ярлык «МиниГен (демоны)»).

### Из репозитория (разработка)

```powershell
cd tools\minigen-gui
npm install          # один раз
npm run dev          # окно с горячей перезагрузкой
```

### Фоновый режим (демоны без окна)

Демонов «МиниГена» (лечащий аккаунтов, сетевой сторож, сторож сессий) держит
эта же программа — в режиме без окна. Он ставится в автозапуск Windows
ярлыком **«МиниГен (демоны)»** и поднимает упавшего демона.

```powershell
python bridge\minigen_bridge.py --daemon      # вручную, для проверки
```

Закрытое окно демонов не убивает: они запускаются отсоединёнными процессами.

### Собранная программа

```powershell
cd tools\minigen-gui
npm run build        # сборка окна
npm run preview      # запуск собранной версии
npm run dist         # установщик (release\МиниГен Setup.exe)
```

Требуется **Python 3.10+** на машине (нужен для моста). Если Python не в
`PATH` — укажите путь: `set MINIGEN_PYTHON=C:\...\python.exe`.

### Проверка без окна

```powershell
python bridge\minigen_bridge.py
# {"id":"1","cmd":"areas.list","args":{}}  — вставить в stdin, получить JSON
```

## Устройство


## Границы

- Программа **не раскатывает** себя на боевую машину — это отдельное действие
  и только по слову владельца.
- Старая веб-панель `:8099`/`:8098` **архивирована** (23.11): её код лежит в
  `tools/minimax-project-areas/archive/`, её функцию покрыло это окно.
- Ключи и токены — только на машине; в репозиторий не попадают.
