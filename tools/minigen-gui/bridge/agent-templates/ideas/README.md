# Агент «Идеи»

Рабочий репозиторий агента-идеи «МиниГена». Здесь лежат:

- `AGENTS.md` — конституция: чем я занимаюсь и чего не делаю;
- `skills/ideas-ingest/SKILL.md` — умение: как превращать зачитку в заявку;
- `requests/<проект>/` — заявки, которые я составил.

Заявки продублированы в **разделах КАРМАНА** (по проекту) — там их видит
владелец и другие агенты. Репозиторий — долговечная копия: переживает
переустановку и восстанавливается из реестра `Valstan/minigen-agents`.
