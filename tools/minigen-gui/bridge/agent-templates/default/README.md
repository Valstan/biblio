# Агент «МиниГен»

Рабочий репозиторий агента. Здесь лежат:

- `AGENTS.md` — конституция агента (что он делает и чего не делает);
- `skills/` — скиллы: как именно он это делает;
- `requests/` — заявки, которые ему поручили.

Репозиторий агента — **приватный**. Агент восстанавливается из реестра
`Valstan/minigen-agents`: манифест + копия конституции и скиллов. Поэтому
всё, что здесь лежит, должно быть восстановимо из GitHub.
