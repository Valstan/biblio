# ymusic — скачивание треков плейлиста Яндекс.Музыки локально

Утилита из репозитория `biblio` (дом desktop-утилит — [D-048](../../docs/DECISIONS.md)
в `brain_matrica`). Канон и грабли — плейбук
`brain_matrica/docs/playbooks/yandex-music-download.md`.

## Что делает

- `list` — треклист плейлиста по ссылке или UUID **без авторизации**.
- `download` — скачивает все треки плейлиста в папку, проставляет теги и встраивает обложки.
- `upgrade` — перебирает качества/кодеки/транспорты и перекачивает в лучшем доступном.
- `tag` — перетегирует уже скачанные файлы в папке (если сменился плейлист или теги).

Файлы получаются с расширением по кодеку (`.m4a` / `.mp3` / `.flac`), имя — `NN. Артист - Название`.

## Установка (один раз на машину)

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```

Ставит `.venv` рядом и пакеты `yandex-music`, `mutagen`, `cryptography`.

## Запуск

Двойной клик по `Запустить.cmd` — меню. Либо из сессии агента:

```
.venv\Scripts\python ymusic.py list https://music.yandex.ru/playlists/<uuid>
.venv\Scripts\python ymusic.py download <uuid> -o D:\Music\my-playlist
.venv\Scripts\python ymusic.py upgrade  <uuid> -o D:\Music\my-playlist --deep
```

## Авторизация

Яндекс отдаёт файлы только авторизованному клиенту (без токена — `403 not-allowed`).
Авторизация — **device flow без пароля**: команда печатает ссылку и код, владелец
подтверждает вход на `https://ya.ru/device`. Токен лежит в `~/.ymusic/token.txt`
(или переменная окружения `YMUSIC_TOKEN`) и **никогда не попадает в git**.

Авторизует официальное приложение Яндекс.Музыки (Android-клиент), а не сторонний
сервис: подпись запросов — HMAC-SHA256 ключом, который сам Яндекс держит в
публичном конфиге своего веб-клиента.

## Ограничения

- Качество отдаёт каталог Яндекса: для части треков это 192 кбит/с AAC, для части —
  320 или FLAC. Лучшее доступное и берётся.
- Лицензия: файлы предназначены для личного использования владельцем подписки.
- `cryptography` нужен только для треков с транспортом `encraw` (шифрованная доставка).

## Секреты

Токен Яндекс.Музыки — секрет: лежит только в `~/.ymusic/`, в репозиторий не
попадает (правило «секреты вне репозитория», #008).
