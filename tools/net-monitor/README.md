# net-monitor — «жив ли интернет» в трее + VPN + DNS

Трей-утилита для Windows 11 (значок рядом с часами). Один файл PowerShell, **ничего не
устанавливает** — ни Python, ни библиотек. Написана Мозгом по заказу владельца 2026-08-26.

## Что показывает

- **Кружок в трее**: 🟢 интернет есть (IP-связь + DNS) · 🟠 частично (например, связь
  есть, а DNS-сервер молчит — частая причина «толи есть интернет, толи нет») · 🔴 нет.
  **Синее кольцо** вокруг кружка = активен VPN.
- **Наведи мышь** — скорость ↓/↑ (видно, что обмен идёт, а не всё зависло), VPN
  (`весь`/`часть`/`нет`), текущие DNS-серверы.
- **Всплывашка** при пропаже/восстановлении интернета — с причиной («IP-связь есть,
  DNS молчит» и т.п.).

## Меню (правый клик по значку)

| Пункт | Что делает |
|---|---|
| Статус сети… | Окно: интернет, через какой интерфейс выход, VPN (и идёт ли через него **весь** трафик или он просто висит), текущие DNS, все живые интерфейсы с адресами |
| Через что идёт сайт… | Вводишь `гоньба.рф` — отвечает: «пойдёт ЧЕРЕЗ VPN» или «НАПРЯМУЮ» (по таблице маршрутов, честно) |
| Тест DNS-серверов… | Меряет скорость текущих + Yandex/Google/Cloudflare/Quad9/AdGuard/OpenDNS на живых доменах; кнопки «Поставить выбранный», «Вернуть автомат (DHCP)» |
| Авто-тест DNS раз в час | Галка: раз в час тест и, если лучший сервер не тот, что стоит, — ставит лучший (нужны права администратора) |
| Автозапуск при входе | Галка: прописывает себя в автозагрузку текущего пользователя (HKCU\\...\\Run) |
| Перезапустить от администратора | Чтобы смена DNS шла без UAC-окон (и работал часовой авто-DNS) |

## Запуск

`Запустить.cmd` (двойной клик). Диагностика одним прогоном без трея:

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File tools/net-monitor/net-monitor.ps1 -Once
```

## Границы и честные оговорки

- **Смена DNS — системная настройка**: без прав администратора каждое применение
  спросит UAC-окно; авто-режим без прав молча пропускает применение (пишет в лог).
- **Якоря «интернет жив» — только крупные хосты** (`77.88.8.8`, `1.1.1.1`, `ya.ru` по
  TCP:443): в некоторых сетях фильтрация режет мелкие сайты при живом интернете —
  иначе были бы ложные «нет интернета».
- **Вердикт «через VPN / напрямую» — по таблице маршрутов** на момент проверки. Split-tunnel
  и правила самого VPN-клиента поверх маршрутов (например, обход по списку доменов
  внутри клиента) утилита видеть не может — она отвечает за то, что решает ОС.
- Скорость считается по интерфейсу маршрута-по-умолчанию; при активном VPN это обычно
  туннель (то, что реально видит приложение).
- Лог: `%LOCALAPPDATA%\net-monitor\log.txt`; настройки: `config.json` там же.

## Если хочется готового вместо/рядом

- [NetSpeedTray](https://github.com/erez-c137/NetSpeedTray) (open source) — красивые
  скорости прямо на панели задач; но без VPN/DNS-логики.
- [DNS Jumper](https://www.sordum.org/7952/dns-jumper-v2-3/) (Sordum, портативный) —
  зрелый тест+смена DNS («Turbo Resolve» ставит быстрейший при старте); но без трея,
  мониторинга и VPN.
- GRC DNS Benchmark — эталонный замер DNS, но ничего не ставит сам.

Наш инструмент — именно «всё в одном взгляде»; эти двое хороши как дополнение.
