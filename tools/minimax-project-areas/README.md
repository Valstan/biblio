# MiniMax Code: изолированный экземпляр на каждый проект

Утилиты владельца для PC79: **свой экземпляр MiniMax Code на каждый проект** — своя
рабочая папка, свои сессии, свой ярлык на рабочем столе, и **в панели задач видно имя
проекта**, а не «MiniMax Code» у всех окон.

## Что внутри

| Файл | Что делает |
|---|---|
| `mcode-project-areas.json` | **единственный источник правды**: 15 проектов (Мозг + 14 клонов) — slug, название для панели задач, папка проекта |
| `mcode-project-start.ps1 -Project <slug>` | запуск изолированного экземпляра проекта: свои каталоги данных, своя папка, свой AUMID, переименование окна |
| `mcode-project-title.ps1 -TargetPid N -Title "..."` | фоновый теггер: держит заголовок окна «<Проект> — MiniMax Code» (приложение само его перебивает) |
| `mcode-project-stop.ps1 [-Project <slug>]` | остановить экземпляр проекта или все (основной десктоп не трогает) |
| `make-mcode-project-shortcuts.ps1` | пересоздать ярлыки рабочего стола; старые ярлыки областей убирает в папку «MiniMax — старые ярлыки» |

Живут в `C:\Users\valstan\bin\` (рядом с прочими лаунчерами MiniMax). Копия здесь — в git.

## Запуск

```powershell
# один проект
powershell -ExecutionPolicy Bypass -File C:\Users\valstan\bin\mcode-project-start.ps1 -Project gonba

# пересоздать все ярлыки рабочего стола
powershell -ExecutionPolicy Bypass -File C:\Users\valstan\bin\make-mcode-project-shortcuts.ps1

# остановить
powershell -ExecutionPolicy Bypass -File C:\Users\valstan\bin\mcode-project-stop.ps1 -Project gonba
```

## Как это устроено

**Изоляция — оба параметра сразу** (иначе изоляции нет):

- `--user-data-dir=<каталог>\electron` — снимает single-instance lock;
- `MINIMAX_DATA_DIR` / `MAVIS_DATA_DIR` — свои auth, сессии, настройки, лимиты.

Каталог данных проекта: `C:\Users\valstan\.minimax-areas\p-<slug>`. Авторизация
копируется из уже авторизованной области (`area1`), иначе на каждый проект нужен
отдельный вход (device-flow, по одному за раз).

**Различимость в панели задач — два независимых рычага:**

- `--app-user-model-id=MiniMaxCode.<slug>` — свой AUMID, окна не группируются;
- переименование окна Win32 `SetWindowText` — метка в панели задач.

Заголовок ставит **фоновый теггер**, а не однократная установка: приложение
переустанавливает «MiniMax Code» сам, и метка без теггера живёт недолго.

## Грабли (см. также пул brain_matrica)

- **PowerShell 5.1 читает `.ps1` без BOM как ANSI** — кириллица в скрипте ломает
  парсер («Unexpected token»). Файлы здесь сохранены **с BOM**.
- **Параметр скрипта не может называться `$Pid`** — это автопеременная PowerShell
  только для чтения («Cannot overwrite variable Pid»).
- **`Start-Process` склеивает `ArgumentList` пробелом без кавычек** — аргумент с
  пробелами разваливается, и фоновый скрипт падает **тихо**.
- **Ярлык и конфиг разъезжаются:** у старых областей `id` не совпадал с проектом,
  и ярлык «МОЗГ» открывал biblio. Источник правды — один json; ярлыки пересоздаются из него.
