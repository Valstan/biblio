# video-downloader — скачать все видео со страницы сайта

Desktop-tool скил Мозга (каркас — [tools/README](../README.md)). Локально,
оффлайн-логика: наружу уходят только сами запросы к сайту за видео.

**Как пользоваться:** кидаешь ссылку на страницу (или несколько) → инструмент
находит на ней все видео (встроенные плееры, HLS-стримы, YouTube/VK/Rutube и
ещё ~1800 площадок) и скачивает в выбранную папку (по умолчанию — «Загрузки»).

## Движок

- **yt-dlp** — экстракция и скачивание. Generic-экстрактор умеет разбирать
  произвольные страницы и вытаскивать встроенные плееры; страница с
  несколькими видео качается целиком (ошибка одного видео не роняет остальные).
- **imageio-ffmpeg** — ffmpeg-бинарник через pip (нужен для склейки
  видео+аудио дорожек и HLS-фрагментов), системная установка не нужна.

## Установка (1 раз на машину)

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```

Повторный запуск безопасен и **обновляет yt-dlp** — сайты меняют плееры,
поэтому при «перестало скачивать с сайта X» первым делом перезапусти установщик.

## Запуск

- Двойной клик по `Запустить.cmd` — откроется окно: ссылки → папка → «Скачать».
- Или из консоли: `.venv\Scripts\python download.py <url> [-o папка] [--audio]`.

## Диагностика

| Симптом | Что делать |
|---|---|
| «не удалось» / Unsupported URL | обновить yt-dlp: перезапустить `install.ps1` |
| скачалось видео без звука | проверь, что установка прошла целиком (ffmpeg из imageio-ffmpeg) |
| сайт требует логина | такие страницы инструмент пока не берёт (нужны cookies — расширение по запросу) |
| качается только часть плееров | пришли ссылку в brain-сессию — посмотрим экстрактор |

## Правовая заметка

Инструмент для личного использования: скачивай то, на что имеешь право
(свои материалы, открытые записи). Ответственность за контент — на пользователе.
