# tools/ — десктоп-утилиты

Локальные утилиты для Windows: «скрипт + GUI», ставятся один раз на машину, работают
оффлайн. Переехали сюда из meta-репо `brain_matrica` решением владельца 2026-08-26
(D-048): biblio — дом утилит, brain — управление экосистемой.

| Инструмент | Что делает | Движок |
|---|---|---|
| [audio-to-text](audio-to-text/) | Пакет аудио (ogg/mp3/…) → русский текст с пунктуацией → блоки → буфер/`.txt` | GigaAM v2 + Silero (CPU, локально) |
| [video-downloader](video-downloader/) | Ссылка на страницу сайта → все видео с неё в выбранную папку (GUI + CLI) | yt-dlp + imageio-ffmpeg |
| [net-monitor](net-monitor/) | Трей-значок «жив ли интернет» + VPN-статус + «через что идёт сайт» + тест/смена DNS | PowerShell + WinForms, ноль зависимостей |
| [kaspersky-matrica](kaspersky-matrica/) | Настройка Касперского под «Матрица РМЗ»: сам находит пути/сервер, даёт готовые строки исключений с копированием, рендерит инструкцию, экспорт-импорт эталона настроек на другие компы | PowerShell + WinForms + `avp.com` |

Тяжёлое (venv, модели) в git не кладётся — см. `.gitignore` внутри каждого инструмента;
установка — `install.ps1` там же (где он есть). Запуск — `Запустить.cmd` в папке инструмента.
